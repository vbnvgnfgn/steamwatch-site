# STEAM WATCH — официальный сайт загрузки проекта

Красочный адаптивный сайт на Flask: загрузка ZIP с программой, список изменений, благодарность тестеру и режим разработчика с проверкой пароля на сервере.

## Запуск на Windows (локально)

1. Установите **Python 3.11+** с https://www.python.org/downloads/ (поставьте галочку *Add Python to PATH*).
2. Распакуйте ZIP с сайтом.
3. Запустите **`Запустить_сайт.bat`**.
4. Откройте **http://127.0.0.1:5000** в браузере (батник также открывает страницу сам).

На первом запуске установятся Flask и Waitress. Для установки потребуется интернет. Пока сайт работает только на вашем компьютере; для доступа извне его нужно опубликовать на хостинге.

Альтернатива — вручную:

```bash
pip install -r requirements.txt
python app.py
```

## Режим разработчика

В самом низу страницы расположена маленькая кнопка **«режим разработчика»**. По умолчанию пароль: **`dev_mode`**. Проверка пароля происходит на сервере, поэтому просто подменить HTML на стороне браузера недостаточно.

В панели можно:

- изменять заголовок, описание, название сайта и прочие подписи;
- редактировать благодарность тестеру;
- добавлять, удалять и редактировать записи ченджлога;
- загружать новый ZIP с программой для посетителей сайта.

Контент хранится в `data/site.json`. Текущий архив хранится в `data/releases/SteamWatch-current.zip`. Исходная версия лежит в `downloads/SteamWatch-v1.0.zip`.

### Важно о защите

**Пароль `dev_mode` предназначен только для демонстрации на локальном компьютере.** Это простой пароль, и он небезопасен для публичного сайта. Перед публикацией установите сложный `ADMIN_PASSWORD`, а также случайный `SECRET_KEY` через переменные окружения хостинга. Используйте HTTPS и включите `SECURE_COOKIES=1`. На сервере есть ограничение попыток входа, CSRF-защита на запросах редактирования и файлы не записываются произвольными путями. Но эти меры не сделают слабый пароль надёжным.

На Windows PowerShell перед запуском вручную можно задать:

```powershell
$env:ADMIN_PASSWORD = 'замените_на_длинный_случайный_пароль'
$env:SECRET_KEY = 'длинная_случайная_секретная_строка'
$env:SECURE_COOKIES = '1'  # ТОЛЬКО если есть HTTPS
python app.py
```

`SECURE_COOKIES=1` не нужно использовать при локальном HTTP (`127.0.0.1`).

## Как опубликовать на своем домене

Вариант — хостинг **Render** (https://render.com/docs/deploy-flask):

1. Загрузите файлы сайта в GitHub-репозиторий. Секретные пароли туда **не** загружайте.
2. Создайте на Render **Web Service** (не Static Site), подключите репозиторий.
3. Build Command: `pip install -r requirements.txt`.
4. Start Command: `sh start.sh`.
5. В Environment задайте `SECRET_KEY`, `ADMIN_PASSWORD` и `SECURE_COOKIES=1`.
6. Настройте постоянное хранилище, доступное по `DATA_DIR`. **Важно:** на хостинге с временной файловой системой данные админ-редактора могут пропасть при новом развёртывании. Render предлагает persistent disks на совместимых тарифах; также можно использовать свой VPS с постоянной папкой `data/`.
7. У регистратора доменов проверьте доступность понравившегося адреса, например `steamwatch.site` (это только идея, не зарегистрированный нами домен). Добавьте домен в настройки сервиса и укажите DNS-записи, которые выдаст хостинг. Подробности: https://render.com/docs/custom-domains.

**Невозможно получить работающий собственный домен одним переименованием сайта.** Потребуются регистрация домена, хостинг и настройка DNS. Доступность и цена `steamwatch.site` не проверялись.

## Содержимое

- `app.py` — серверная логика, загрузка файлов, вход и сохранение изменений;
- `templates/index.html` — HTML главной страницы;
- `static/style.css`, `static/app.js` — дизайн и интерактивность;
- `static/favicon.svg` — иконка сайта;
- `downloads/SteamWatch-v1.0.zip` — комплект программы;
- `requirements.txt`, `start.sh` — окружение и запуск.

Программа мониторинга использует Steam Store API для поиска и цен, а историю скидок получает через IsThereAnyDeal при наличии API-ключа. Изменён только бренд в надписях: данные отслеживания оставлены в `%APPDATA%\\NeonSteamWatch` ради совместимости со старой установкой.

**Неофициальный проект. Не связан с Valve или Steam.**
